Instalación desde cero

Configura GRIT APP en una computadora nueva. Selecciona tu sistema operativo para ver sus comandos y continúa con los pasos compartidos.

↗ Backend · Laravel↗ Frontend · Ionic + Angular
Estos proyectos ya existen en GitHub. No es necesario volver a ejecutar composer create-project, ionic start ni ng add @angular/pwa al clonar.

1. Preparar la computadora

Elige tu sistema operativo. El resto del manual se adapta automáticamente.

1. Git, PHP y extensiones

sudo apt update
sudo apt install -y git php-cli php-mbstring php-xml php-curl php-zip php-sqlite3 unzip curl

2. Composer

Instálalo siguiendo la guía oficial de Composer. Comprueba que se puede ejecutar desde cualquier carpeta.

3. Node.js con nvm

Instala nvm, cierra y vuelve a abrir la terminal y ejecuta:

nvm install --lts
nvm use --lts

1. Git

Instala Git for Windows y abre PowerShell. También puedes usar Git Bash para Git, pero los comandos de esta sección son de PowerShell.

2. PHP + extensiones

Instala PHP para Windows desde windows.php.net o mediante un entorno compatible que lo incluya. Agrega PHP al PATH y activa mbstring, fileinfo, openssl, pdo_sqlite, pdo_mysql o pdo_pgsql según la base de datos, además de las extensiones requeridas por el proyecto. Verifica el archivo php.ini efectivo con php --ini.

3. Composer

Ejecuta el instalador Composer-Setup.exe y selecciona el ejecutable de PHP instalado. Reinicia PowerShell tras instalarlo.

4. Node.js

Instala la versión LTS compatible desde nodejs.org. Si el repositorio incluye .nvmrc, utiliza una versión de Node que coincida con ese archivo. Reinicia PowerShell.

1. Herramientas de desarrollo

Abre Terminal e instala las herramientas de línea de comandos de Apple. Si ya las tienes, el sistema lo indicará.

xcode-select --install

2. Homebrew, Git, PHP y Composer

Instala Homebrew siguiendo su sitio oficial y asegúrate de que brew esté en tu PATH. Luego ejecuta:

brew install git php composer

Comprueba las extensiones cargadas con php -m. Instala o habilita cualquier extensión específica requerida por Laravel y la base de datos.

3. Node.js con nvm

Instala nvm, reinicia la terminal y ejecuta:

nvm install --lts
nvm use --lts

4. Verificar herramientas

git --version
php -v
composer --version
node -v
npm -v

5. Instalar Ionic CLI

npm install -g @ionic/cli
ionic --version
Comprueba que PHP cumpla las restricciones de composer.json y Node las de package.json / .nvmrc. No asumas que la versión LTS más reciente es compatible.

2. Clonar los repositorios

mkdir -p ~/gritapp
cd ~/gritapp
git clone https://github.com/DessRJ/grit-app-backend.git
git clone https://github.com/DessRJ/grit-app-frontend.git
New-Item -ItemType Directory -Force -Path "$HOME\gritapp"
Set-Location "$HOME\gritapp"
git clone https://github.com/DessRJ/grit-app-backend.git
git clone https://github.com/DessRJ/grit-app-frontend.git

Para repositorios privados, autentícate mediante SSH o un token personal al usar HTTPS. No compartas ni guardes tokens en archivos del proyecto.

Ambos proyectos quedan dentro de una carpeta gritapp.

3. Configurar el backend

Abre una terminal en la carpeta grit-app-backend.

cd ~/gritapp/grit-app-backend
composer install
cp .env.example .env
php artisan key:generate
Set-Location "$HOME\gritapp\grit-app-backend"
composer install
Copy-Item .env.example .env
php artisan key:generate

Base de datos

Abre .env con tu editor de texto y configura el motor que utilizará GRIT APP. Dos ejemplos alternativos:

SQLite
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000
DB_CONNECTION=sqlite

Si utilizas SQLite, crea database/database.sqlite en caso de que aún no exista.

MySQL
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=grit_app
DB_USERNAME=grit_user
DB_PASSWORD=CONTRASENA_LOCAL

Para MySQL se requiere el servidor, la base de datos, usuario y extensión pdo_mysql. Para PostgreSQL configura su driver y variables correspondientes.

Crear tablas e iniciar Laravel

php artisan migrate
php artisan serve

Laravel estará normalmente en http://127.0.0.1:8000. Las migraciones crean la estructura, pero no recuperan datos de producción. Nunca ejecutes migraciones sobre una base existente sin validar su impacto.

4. Configurar el frontend

Abre una segunda terminal.

cd ~/gritapp/grit-app-frontend
npm ci
ionic serve
Set-Location "$HOME\gritapp\grit-app-frontend"
npm ci
ionic serve

Si no existe package-lock.json, utiliza npm install en vez de npm ci.

API de Laravel

Revisa cómo configura el frontend la URL de la API. Si utiliza src/environments/environment.ts, una configuración posible es:

export const environment = {
  production: false,
  apiUrl: 'http://localhost:8000/api'
};

Este archivo es solo un ejemplo: utiliza la configuración real del repositorio. Asegúrate de configurar CORS en Laravel si corresponde.

Ionic se inicia normalmente en http://localhost:8100.

5. Verificar la PWA

Comprueba que el proyecto tenga manifiesto web, service worker y configuración de producción. Compila desde grit-app-frontend:

npx ng build --configuration production

Prueba la compilación con un servidor en localhost o HTTPS. ionic serve no siempre habilita el service worker de producción.

6. Trabajo diario

Después de instalar todo, basta con abrir dos terminales.

Backend · Terminal 1

cd ~/gritapp/grit-app-backend
php artisan serve
Set-Location "$HOME\gritapp\grit-app-backend"
php artisan serve

Frontend · Terminal 2

7. Actualizar el código

Comprueba primero si tienes cambios locales con git status en cada repositorio.

Backend

git pull origin main
composer install

Aplica php artisan migrate solo cuando corresponda.

Frontend

git pull origin main
npm ci

Ejecuta cada bloque desde la carpeta de su repositorio. No hagas git pull a ciegas si tienes cambios pendientes.

8. Problemas habituales

ProblemaQué revisar
php o composer no reconocidoInstalación y PATH; reiniciar terminal
npm / ionic no reconocidoNode, npm, CLI y PATH
vendor/autoload.phpEjecutar composer install
APP_KEY no configurada.env y php artisan key:generate
La BD no conectaDriver PHP, servicio, usuario y .env
API bloqueada por CORSOrigen permitido y configuración Laravel
Git no autenticaToken personal o SSH
Nunca subas a GitHub el archivo .env, contraseñas ni tokens. Conserva composer.lock y package-lock.json en el repositorio.
