Configuración del entorno local

Guía para instalar el backend y el frontend desde una computadora nueva con Ubuntu.

Antes de empezar

Este proceso se realiza una sola vez en cada computadora. Después, para trabajar, basta con iniciar ambos servidores locales.

↗ Repositorio backend↗ Repositorio frontend

Ubuntu · Laravel / PHP · Ionic / Angular · PWA

Los proyectos ya están creados en GitHub. No ejecutes composer create-project ni ionic start al instalarlos en una máquina nueva.

1. Preparar Ubuntu

Actualizar e instalar Git

sudo apt update
sudo apt upgrade -y
sudo apt install git -y
git --version

Instalar PHP y extensiones

sudo apt install -y php-cli php-mbstring php-xml php-curl php-zip php-sqlite3 unzip curl
php -v

La versión de PHP debe cumplir con los requisitos del composer.json. Para MySQL o PostgreSQL, instala también php-mysql o php-pgsql.

Instalar Composer

Sigue el instalador oficial en getcomposer.org/download y verifica:

composer --version

Node.js, npm e Ionic

Instala NVM desde su repositorio oficial. Luego instala una versión de Node compatible con el proyecto:

nvm install --lts
nvm use --lts
node -v
npm -v
npm install -g @ionic/cli
ionic --version
Si el frontend incluye .nvmrc, prioriza esa versión de Node usando nvm install y nvm use.

2. Descargar el código

mkdir -p ~/gritapp
cd ~/gritapp
git clone https://github.com/DessRJ/grit-app-backend.git
git clone https://github.com/DessRJ/grit-app-frontend.git

Si los repositorios son privados, autentícate con un token de GitHub para HTTPS o con SSH. Nunca guardes tokens dentro del proyecto.

3. Configurar Laravel

Instalar dependencias

cd ~/gritapp/grit-app-backend
composer install

Crear el entorno local

cp .env.example .env
php artisan key:generate
nano .env

Configura las variables de aplicación y de base de datos según el motor que utilice GRIT APP.

Ejemplo SQLite

APP_NAME="GRIT APP"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000
DB_CONNECTION=sqlite
touch database/database.sqlite

Ejemplo MySQL (alternativa)

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=grit_app
DB_USERNAME=grit_user
DB_PASSWORD=CONTRASENA_LOCAL
Si usas MySQL, crea antes la base de datos y el usuario. Estos son ejemplos alternativos, no debes configurar ambos motores a la vez.

Migraciones e inicio

php artisan migrate
php artisan serve

Laravel suele estar disponible en http://127.0.0.1:8000. Las migraciones crean tablas, pero no restauran datos de un respaldo.

4. Configurar Ionic + Angular

Instalar dependencias

cd ~/gritapp/grit-app-frontend
npm ci

Usa npm ci cuando exista package-lock.json; de lo contrario, utiliza npm install.

Conexión con el backend

Localiza la configuración de entornos del frontend y apunta el servicio HTTP a Laravel. Si el proyecto utiliza src/environments/environment.ts, la configuración podría verse así:

export const environment = {
  production: false,
  apiUrl: 'http://localhost:8000/api'
};

Comprueba también la configuración CORS del backend.

Iniciar Ionic

ionic serve

Frontend disponible habitualmente en http://localhost:8100.

5. Validar la PWA

Verifica que el frontend ya incluya manifiesto web, service worker y configuración de producción.

cd ~/gritapp/grit-app-frontend
npx ng build --configuration production

Para verificar la instalación de la PWA, sirve la compilación de producción en localhost o mediante HTTPS. ionic serve no garantiza la activación del service worker de producción.

6. Iniciar GRIT APP cada día

Abre dos terminales y mantén ambos procesos ejecutándose:

Terminal 1 · Laravel

cd ~/gritapp/grit-app-backend
php artisan serve

Terminal 2 · Ionic

cd ~/gritapp/grit-app-frontend
ionic serve
ServicioDirección
Backendlocalhost:8000
Frontendlocalhost:8100
API, según las rutaslocalhost:8000/api/...

7. Descargar actualizaciones

Antes de actualizar cualquiera de los repositorios, ejecuta git status y revisa tus cambios locales.

Backend

cd ~/gritapp/grit-app-backend
git pull origin main
composer install
php artisan migrate

Ejecuta migraciones cuando el proyecto incorpore cambios de esquema y tengas un respaldo si corresponde.

Frontend

cd ~/gritapp/grit-app-frontend
git pull origin main
npm ci

9. Lista de verificación

Seguridad: no subir .env ni tokens a GitHub. Mantener los archivos de bloqueo de dependencias versionados y desactivar APP_DEBUG en producción.
